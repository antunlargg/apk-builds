# apk-builds

Tired of searching for APKs online only to end up with XAPK, APKM, and countless other formats? This repository is made for people who just want a simple, standard APK file that can be installed directly on Android.

The goal of **apk-builds** is simple: download a regular `.apk` file and install it without dealing with complicated package formats.

## What is this?

**apk-builds** is a collection of APK builds that are ready to download and install. The repository focuses on standard APK files whenever possible.

Android applications can be distributed in several different formats:

- `.apk` — standard Android application package
- `.xapk` — APK package that can include additional files such as OBB data
- `.apkm` — package commonly containing split APKs
- `.apks` — collection of split APK files

These formats can be useful, but they may require additional installation tools or steps. This repository focuses on regular APK files for a simpler experience.

## Installation

1. Download the APK you want.
2. Open the downloaded `.apk` file on your Android device.
3. If Android asks, allow installation from unknown sources for the application you are using to install the APK.
4. Install the application.
5. Launch it normally.

Some applications may require additional permissions or a specific Android version.

## Compatibility

Compatibility depends on the individual APK. Before installing, check:

- Android version requirements
- CPU architecture
- Required permissions
- Whether the APK is universal or architecture-specific

Common Android architectures include:

- `arm64-v8a`
- `armeabi-v7a`
- `x86`
- `x86_64`

If an APK does not install, it may be incompatible with your device, Android version, or CPU architecture.

## Versions

Older versions may be kept when useful. An older APK can be useful if:

- A newer version no longer supports an older Android release.
- A newer update introduces bugs.
- You need a specific version.
- You prefer an older interface or feature set.

When possible, use the newest version compatible with your device.
